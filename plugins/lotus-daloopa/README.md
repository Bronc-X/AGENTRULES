# Lotus Daloopa Plugin

This plugin keeps Daloopa's nine selected financial workflows behind one top-level `daloopa` entry.

Included internal workflows:

- `setup`
- `build-model`
- `bull-bear`
- `capital-allocation`
- `earnings-flash`
- `earnings-prep`
- `ib-deck`
- `precedent-transactions`
- `research-note`

The router lives at `skills/daloopa/SKILL.md`. The workflow packages, shared data-access rules, design system, app connector, icon, and upstream Apache-2.0 license are bundled with it.
