# 资产规划

内容母库是唯一共同上游。不要从未经确认的原始转写直接各写一遍，否则人物、数字和版本会漂移。

## 状态

每个分支只能使用：

- `SELECTED`：用户本轮明确要做。
- `OPTIONAL`：有价值但尚未选择。
- `SKIPPED`：用户明确不要。
- `BLOCKED`：已选择，但缺证据、权限、输入或 QA。
- `COMPLETE`：产物完成且该分支 QA 通过。

`OPTIONAL` 不是待自动执行队列。用户说“继续”时，只继续 `SELECTED` 或 `BLOCKED` 中已解除阻塞的分支。

## 分支清单

| 分支 | 常见资产 | 额外门禁 |
|---|---|---|
| podcast | 选题、分集结构、逐字脚本、show notes、章节、原声/旁白清单、母带 | 原声权、声线权、人工全听审 |
| article | 长文、公众号稿、专访、摘要、标题组 | 引语与事实复核、隐私审查 |
| video | 短视频脚本、分镜、字幕、镜头清单、数字人版本 | 画面权、音乐/素材权、声线和形象权 |
| social | 朋友圈、小红书、LinkedIn、微博候选 | 平台语气、隐私、账号级发布确认 |
| knowledge | 会议纪要、FAQ、决策记录、行动项、知识条目 | 内部可见范围、保留策略、上传确认 |
| commercial | 客户案例、销售 battlecard、演讲稿、白皮书素材 | 客户公开许可、数字和效果声明复核 |

## 选择方法

1. 从用户原话提取明确选择和排除。
2. 根据证据密度、时效、敏感度和制作成本给出最多三个 `OPTIONAL` 建议。
3. 将选择写入 `plans/ASSET_PLAN.json`，补充目标受众、长度、语气、截止时间和依赖。
4. 在 `plans/ASSET_PLAN.md` 中给用户一个可读视图。
5. 只读取并执行所选分支的 reference。

用户没有指定资产时，完成母库后停在规划阶段，给出建议及理由，不自行推进。

## 证据绑定

每个分支产物都要有 `evidence_map`，至少列出：

```text
artifact section / claim id / quote id / source turn ids / editorial transformation
```

标题和叙事连接句可以是编辑创作，但不得引入录音外的具体事实。确需外部研究时，另列外部来源，不与录音证据混为一谈。

## 完成定义

分支标记 `COMPLETE` 需同时满足：

- 产物存在，版本与输入母库哈希一致。
- 实质性陈述可追溯。
- 未确认身份、受限内容和个人信息没有泄漏。
- 对应风格与技术 QA 通过。
- 仍未授权的原声、声线、上传和发布保持阻断。

“本阶段完成”可以与“公开发布仍未授权”同时成立。
