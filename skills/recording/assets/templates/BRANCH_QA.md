## 检查

- [ ] 实质性陈述全部有 claim/quote/turn 证据。
- [ ] 冲突数字、被推翻决定和待确认内容没有写成事实。
- [ ] `UNKNOWN/UNRESOLVED/CLUSTER-*` 没有进入对外资产。
- [ ] 受限内容和个人信息没有在正文、标题、标签、文件名或元数据泄漏。
- [ ] 人物显示名、公开身份、原声、声线、形象和发布权限均在作用域内。
- [ ] 分支媒介与风格检查通过。
- [ ] 输出路径和 SHA-256 已记录。

### 播客附加检查（仅 podcast）

- [ ] 分集来自完整会议主题图，单集优选 30–60 分钟但未为时长硬切主题。
- [ ] 已记录每集总时长、原声时长、旁白时长和原声占比。
- [ ] 正式长访谈原声占比 `≥90%`，目标 `≥95%`。
- [ ] AI 只承担固定开场和不可替代的极少串场，没有全旁白摘要。
- [ ] 旁白类型只有 `INTRO / NECESSARY_TRANSITION`，且每段都有不可替代理由。
- [ ] 每段入选原声已完整回听上下文并取得对应原声权。
