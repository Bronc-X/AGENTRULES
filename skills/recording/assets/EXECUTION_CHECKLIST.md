# Recording 项目执行单

## 0. 项目契约

- [ ] 已记录项目、时区、来源、用户选择的资产和明确排除项。
- [ ] 已确认哪些内容只能内部使用，哪些可能进入公开资产。
- [ ] 已选用正确品牌配置；非 DeepEvolutions 项目未继承其固定开场。

## 1. 原音冻结

- [ ] 活跃/partial 文件为 0，所有输入可完整解码。
- [ ] `source-manifest.json` 包含稳定 source ID、相对路径、字节和 SHA-256。
- [ ] 原音保持只读；工作转码放在 `work/`。
- [ ] 已记录缺口、静音、重叠、补录和轨道信息。

## 2. 逐轮证据

- [ ] 每轮可追溯到 source ID、轨道、源文件时间和源 SHA。
- [ ] 机器原文与规范化文字分开保存。
- [ ] 重叠内容有共同 group ID，母库只计一次。
- [ ] 听不清、冲突和低置信度没有被自动“修正”。

## 3. 正式范围

- [ ] 正式零点、排除区间、受限区间和补录范围有明确决定。
- [ ] `formal 00:00:00.000` 可映射到源文件、会话时间和绝对时间。
- [ ] `EXISTENCE_ONLY` 区间未被转写、摘要、索引或写入元数据。

## 4. 人物与权限

- [ ] 稳定匿名人物与显示名分开。
- [ ] `UNKNOWN/UNRESOLVED` 只留证据层。
- [ ] 显示名、公开身份、文字、原声、声线、形象、上传和发布分别记录。
- [ ] 所有批准均绑定作用域、用户原话、时间和文件哈希。

## 5. 内容母库

- [ ] 正式全文、主题、主张、引语、人物、术语、决策、行动项和疑点齐全。
- [ ] 冲突主张与被推翻决定没有被写成最终事实。
- [ ] 引号只来自 `EXACT` 或 `NORMALIZED_EXACT`。
- [ ] 个人信息匿名策略已统一执行。

## 6. 资产规划

- [ ] 用户选中的分支为 `SELECTED`，未选分支仍为 `OPTIONAL/SKIPPED`。
- [ ] 每个分支记录受众、交付物、依赖和证据映射。
- [ ] 用户说“继续”时没有扩大分支或授权范围。

## 7. 分支生产与 QA

- [ ] 只生产所选分支。
- [ ] 每个实质性陈述能回到 claim/quote/turn。
- [ ] 分支事实、权限、隐私、风格和技术 QA 通过。
- [ ] 播客/视频涉及声线或形象时，试音、批量和形象批准相互独立。
- [ ] 播客集数来自完整会议主题图，不是预设数量；单集优选 30–60 分钟但不硬切。
- [ ] 正式长访谈版以原声为主体，原声占比不低于 90%、目标不低于 95%；AI 仅固定开场和极少必要串场。
- [ ] 原声权未完成时没有用全 Toni 旁白版冒充正式长访谈。

## 8. 发布候选

- [ ] 用户确实选择了上传或发布；否则项目已在分支 QA 后停止。
- [ ] 公开内容与内部审阅内容分开。
- [ ] 内容、文件、平台、账号和 SHA 已冻结并展示预览。
- [ ] 无占位词、内部标记、内部路径、未知人物或个人隐私泄漏。

## 9. 单独发布授权

- [ ] 用户对当前候选、具体平台和具体账号再次明确确认。
- [ ] 候选在确认后没有改变；若改变，已重新确认。
- [ ] 一个平台/资产的确认没有扩展到其他平台/资产。

## 10. 发布后验证

- [ ] 已分别记录上传、公开、直链可达、搜索索引和地区可见状态。
- [ ] 失败时已停止并报告，没有猜账号、跨平台补发或无限重试。
- [ ] 项目完成，同时未授权范围仍保持阻断。
